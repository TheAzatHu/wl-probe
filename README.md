# wl-probe

Сборщик и валидатор публичных VLESS-конфигураций.

Раз в час GitHub Actions забирает списки из открытых источников, приводит их к
единому виду, честно дедуплицирует и проверяет каждый узел **реальным проходом
трафика** через Xray — а не только доступностью TCP-порта. Результат
складывается в `results/`.

## Результаты

| Файл | Что внутри |
|---|---|
| `results/alive.txt` | Узлы, прошедшие HTTP-проверку. Метка вида `[CC=DE][POOL=GENERAL][ASN=24940] Hetzner` |
| `results/alive_ru.txt` | Только российские узлы — для сценария белых списков |
| `results/alive.jsonl` | То же с полями: RTT, ASN, провайдер, источник |
| `results/stats.json` | Сводка: сколько живо, по странам, по источникам, по ASN |
| `results/sources/` | Отчёт по каждому источнику: что скачалось, что отпало |

## Как устроена проверка

**Стадия A — синтаксис.** Разбор URI, проверка UUID, порта, обязательных
параметров Reality. Отбрасываются `0.0.0.0`, битые строки, неподдерживаемые
транспорты.

**Стадия B — доступность.** TCP-подключение с замером времени. Сама по себе
успехом не считается.

**Стадия C — реальный трафик.** На каждый узел поднимается отдельный Xray с
локальным SOCKS-портом, через него выполняются запросы к контрольным адресам.
Узел считается живым, только если трафик реально прошёл.

**Стадия D — цепочка** выполняется не здесь, а на стороне потребителя: только
он знает адрес своего выходного сервера.

## Дедупликация

Отпечаток узла считается по полному набору: адрес, порт, UUID, security, flow,
транспорт, SNI, Reality public key, short ID, fingerprint, path, Host,
serviceName, ALPN, packet encoding.

Два конфига на одном `IP:порт` — **разные**, если у них разные SNI, ключи или
транспорт. Схлопывание по `IP:порт` теряет рабочие варианты, поэтому здесь так
не делается.

## Карантин

Конфигурации `xhttp` и `h2` собираются и считаются, но не публикуются: их
поддержка сильно зависит от версии клиентского ядра. Они отражены в статистике
как `quarantined_xhttp` и ждут отдельной проверки совместимости.

## Квоты разнообразия

- не более 4 узлов на одну автономную систему (ASN);
- не более 2 конфигураций на один `IP:порт`.

Иначе список вырождается в один хостинг, который отключат целиком.

## Источники

Перечислены в [`sources.yml`](sources.yml) с категорией и уровнем доверия.
Все данные берутся из публичных репозиториев их авторов.
